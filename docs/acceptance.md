# 验收：重建之后拿什么证明你建对了

这份文档是给**从文档重建这套引擎的人**用的。其余三份告诉你该建什么，这一份给你
可以立刻跑、可以逐位对照的数——以及一张必须成立的不变量清单。

先读 `architecture.md` §6.2（算子的精确语义）与 §6.3（指纹），再回来跑这里的例子。

## 1. 算子链：一个可以手算的截面

六只票，其中 **106 在池外**、**104 的 handle 值是 NaN**、**105 的分组字段缺失**、
`10` 组有两只而 `20` 组也有两只（其中一只值为 NaN）。这四种情形各自触发一条容易写错的规则。

**输入**

| security_id | 101 | 102 | 103 | 104 | 105 | 106 |
|---|---|---|---|---|---|---|
| `raw`（handle 返回） | 3.0 | 1.0 | 2.0 | **NaN** | 5.0 | 9.9 |
| `sector`（分组字段） | 10 | 10 | 20 | 20 | **NaN** | 10 |
| `universe` | ✓ | ✓ | ✓ | ✓ | ✓ | **✗** |

ops 链：`[rank, neutralize: sector, truncate: 0.30, scale: book]`

**逐步输出**（每一步都是上一步的输入）

| 步 | 101 | 102 | 103 | 104 | 105 | 106 |
|---|---|---|---|---|---|---|
| ① 闸门一（池外→NaN） | 3.000000 | 1.000000 | 2.000000 | NaN | 5.000000 | **NaN** |
| ② `rank` | 0.166667 | −0.500000 | −0.166667 | NaN | 0.500000 | NaN |
| ③ `neutralize: sector` | 0.333333 | −0.333333 | 0.000000 | NaN | 0.000000 | NaN |
| ④ `truncate: 0.30` | 0.200000 | −0.200000 | 0.000000 | NaN | 0.000000 | NaN |
| ⑤ `scale: book` | **0.500000** | **−0.500000** | 0.000000 | **0.000000** | 0.000000 | **0.000000** |

**每一步该对上的地方**

- **①** 池外的 106 被压成 NaN，**在任何截面统计之前**。若你只在输出端掩码，
  ② 的 `rank` 会把 106 算进 `m`，六个数的名次与五个数的名次不同，后面全错。
- **②** 有效个数 `m = 4`（101/102/103/105）。名次 `[3,1,2,4]` → `(r−1)/3 − 0.5`
  = `[0.166667, −0.5, −0.166667, 0.5]`。**端点取到 ±0.5**；若你用 `r/(m+1) − 0.5`
  会得到 `[0.1, −0.3, −0.1, 0.3]`——形状像，数全不一样。
- **③** 组 `10` = {101, 102}，均值 `(0.166667 − 0.5)/2 = −0.166667`，故 101 → `0.333333`。
  组 `20` = {103, 104}，104 是 NaN 不拉偏均值，组均值 = `−0.166667`，103 → `0.0`。
  105 的分组字段是 **NaN，自成一组**（`dropna=False`），单元素组 demean 后恒为 `0.0`。
  > 若你用 pandas 默认的 `dropna=True`，105 会**变成 NaN**——覆盖率悄悄掉一只，不报错。
- **④** `gross = 0.333333 + 0.333333 = 0.666667`（**截断前**），`cap = 0.30 × 0.666667 = 0.2`。
  101/102 被夹到 ±0.2。**单次夹紧，不迭代**：若你迭代到不动点，gross 会随每次夹紧变小，
  这个例子会收敛到全 0。
- **⑤** 先掩码再算 gross：`gross = 0.4`，`0.2/0.4 = 0.5`。收口把 NaN 与池外**都变 0**
  （不是 NaN）。最终 `Σ|w| = 1.000000`，池外 106 恰为 `0.0`，NaN 位 104 恰为 `0.0`。

## 2. `linear_decay: 3`：预热与 NaN 权重

同一条 buffer 连喂四天，第二列第 0 天是 NaN：

| t | 输入 | 输出（第 1 列） | 输出（第 2 列） |
|---|---|---|---|
| 0 | `[1.0, NaN]` | 1.000000 | NaN |
| 1 | `[2.0, 4.0]` | 1.600000 | 4.000000 |
| 2 | `[3.0, 6.0]` | 2.333333 | 5.200000 |
| 3 | `[4.0, 8.0]` | 3.333333 | 6.666667 |

手算 `t=2`：

```
第 1 列：(3·3 + 2·2 + 1·1) / (3 + 2 + 1) = 14/6 = 2.333333
第 2 列：(3·6 + 2·4)       / (3 + 2)     = 26/5 = 5.200000
                                             ↑ t=0 是 NaN, 它的权重 1 不进分母
```

**分母是有效权重之和，不是常数 `n(n+1)/2`。** 若你用常数分母，第 2 列 `t=2` 会得到
`26/6 = 4.333333`——每逢缺一天就整体缩水一次，而且不报错。

`t=0` 与 `t=1` 的输出是"缓冲未填满"的产物：它们**合法但不该被采纳**，这正是预热存在
的理由。`ops_lookback([("linear_decay", 3)]) = 2`，即链要 2 天先前历史。

## 3. 不变量清单

按"违反时会发生什么"排序，前面几条都是**静默给出错数**，不是崩溃。

| # | 不变量 | 违反的后果 |
|---|---|---|
| I1 | **一个 session 的值不取决于从哪天起跑**（预热 = 声明值 **+** ops 贡献，相加） | 起跑后前几天的输出来自未填满的缓冲。实测 501/503 只票全不一样、最大差 0.11，无任何告警 |
| I2 | `di` 恒为第一轴；轴 **append-only**，非扩展的重放被拒 | 日历里补一天，全库面板整体错开一天 = 一次性给每个 alpha 注入一天前视 |
| I3 | 引用名 ↔ 路径是**全双射**，含折叠规则；展开形被拒 | 同一份数据两种拼法，hash 出两个指纹却指向同一个数组 |
| I4 | 两道掩码闸门：ops **之前**池外整列 NaN，`scale` **之后**池外恰为 0 | 见 §1 的 ① 与 ⑤；只做一端两条承诺不能同时成立 |
| I5 | 指纹在**任何写入之前**比对（§6.3），组成逐字一致 | 改一行公式跑日更，同一个数组里改动日前后是两个定义 |
| I6 | 输出键集**逐日恒定**；算不出值传 NaN，**漏 key 是结构错误** | NaN = 这天这只票没有值；漏 key = 这个节点今天不存在 |
| I7 | alpha 必须是秩-2，ops 链必须以 `scale` 收尾 | 上游各自 `Σ\|w\|=1` 的权重线性组合后因抵消缩水，账本投不满而 Sharpe 看着正常 |
| I8 | CS 算子**只对秩-2**合法 | 秩-3 的截面轴不唯一，猜一个默认值等于悄悄换口径 |
| I9 | `fill_value` 显式：浮点 NaN，其余 0/False | bool 面板未覆盖列若变 True，池外的票会被标成池内 |
| I10 | 停牌日的 NaN **不得进入推进式** | `pos × (1 + NaN)` 摧毁持仓并向后传染 |
| I11 | `frozen_value` 是两侧 **gross**，不是带符号和 | 多空相抵后约等于 0，`avail ≈ booksize`，冻结重分配等于没做 |
| I12 | `return` 的分母**恒定为 booksize** | 用上期净值会让复利效应混进 Sharpe |
| I13 | 权重的日期轴在 session 轴上**连续** | 跨洞仿真把洞后第一天的收益施加到洞前的持仓上，两个月价格变动凭空消失 |
| I14 | 没有判据的闸门报 **NO-BASIS**，不报 PASS | 空白在"干净"与"没查"之间有歧义 |
| I15 | 半成品数组（属性未提交）**不算存在** | 它会被 `effective_ed` 当成"完全新鲜"，零数据预检把一具尸体判成活的 |
| I16 | 算子清单单一出处，实现方自证覆盖 | 编译期认得而执行期不认得的算子，或反之 |
| I17 | `region_hash` 只覆盖**口径**键，不含路径键 | 研究员换台机器写个绝对路径，就和队友被判成口径分叉 |

## 4. 自检顺序

1. **先建 §1 的六只票，逐步比对五行输出。** 全部对上，说明 `rank` 的端点约定、
   `neutralize` 的 `dropna=False`、`truncate` 的不迭代、`scale` 的先掩码后归一
   四件事都对了——这四件是最容易写成"看着像"的地方。
2. **再跑 §2 的四天。** 对上说明 NaN 按权重 0 参与、且分母是有效权重之和。
3. **然后验 I1**：任取一个带 ops 的节点，用两个不同的 `--sd` 各跑一次，
   比较重叠区间——必须逐位相同。
4. **最后验 I3**：把库里每个 ref 拆成路径再拼回来，必须逐字还原；
   并确认展开形被拒绝。

前两步不需要 store，纯内存即可；后两步需要一个可写的 L3。
